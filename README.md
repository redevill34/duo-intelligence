# DUO Intelligence V1 (prototype)

Espace privé pour deux partenaires. React + TypeScript (TanStack Start), Tailwind, PWA installable (manifeste seul).

## Installation
`bun install` puis `bun run dev`. Tests : `bunx vitest run`. Aucune variable requise (voir `.env.example`).

## Limites
Données fictives en mémoire, IA simulée, aucun backend, aucune sécurité réelle. Voir `docs/`.
